將捷旅境 — 單機版網站使用說明
=====================================

■ 如何開啟
  1. 把整個「project_html」資料夾複製到電腦任意位置（桌面、隨身碟皆可）。
  2. 在資料夾內的「index.html」上點兩下，即會用預設瀏覽器開啟。
     （若沒有反應，請在 index.html 上按右鍵 →「開啟檔案的應用程式」→ 選 Chrome 或 Edge）

  不需要安裝任何程式，也不需要架設伺服器。


■ 使用注意事項
  ‧ 建議瀏覽器：Google Chrome 或 Microsoft Edge（最新版）。
  ‧ 建議螢幕寬度 1025 像素以上；視窗太窄會顯示「請切換大螢幕獲得更好體驗」。
    若出現該訊息，請把瀏覽器視窗放到最大，或按 F11 進入全螢幕。
  ‧ 沒有網路也可以正常使用，所有圖片與影片都在資料夾內。
  ‧ 資料夾內的檔案請勿刪除、改名或搬移，否則圖片會顯示不出來。
  ‧ 整包資料夾約 640 MB，複製時請等候完成。


■ 資料夾內容
  index.html   ← 網站入口，點這個開啟
  assets/      網頁程式與樣式
  img/         所有圖片與影片
  vendor/      無網路時使用的套件備份檔


■ 常見問題
  Q：畫面一片空白？
  A：請改用 Chrome 或 Edge 開啟；若仍空白，請確認 index.html 與 assets、img、
     vendor 三個資料夾在同一層。

  Q：網址列出現一長串 file:///... 是正常的嗎？
  A：正常。單機版是直接讀取本機檔案，網址就會是這種格式。

  Q：可以放到隨身碟給別人嗎？
  A：可以，整包複製即可。
